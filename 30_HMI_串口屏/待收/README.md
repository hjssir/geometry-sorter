## 3 给你的自测方法（不接主控，USB-TTL 直接灌）

| 检查项 | 怎么测 | 通过标准 |
|---|---|---|
| 波特率 | 9600 / 115200 各发一次 `t0.txt="hi"` + `FF FF FF` | 只有一个生效——记下是哪个 |
| 文本控件 | `t0.txt="测试"` | 屏上出字（乱码=编码问题） |
| 数字控件 | `t1.val=7` | 屏上显示 **7**（不是文字 "7" 卡住不动） |
| 错误回包 | 观察 USB-TTL 收到的回包 | 能收到 `1C FF FF FF` 等错误码 → 屏在回应，线是通的 |

> 判据：**文字能动、数字不动 = 控件类型问题**（不是接线）；**连文字都不动 = 先查波特率**。
