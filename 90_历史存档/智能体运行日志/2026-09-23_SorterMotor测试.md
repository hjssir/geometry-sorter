## 1. 测试现象

- 测试程序设定 `STEPS_PER_REV = 3200`（按任务假设 A4988 为 1/16 细分）。
- 阶段「正转一圈」执行 `moveTo(3200)` 后，**电机实际转动了 2 圈**。

## 2. 结论

- 3200 步 = 2 圈 → **每圈 = 1600 步**。
- 电机 1.8°（200 步/圈），1600 = 200 × 8 → **A4988 实际为 1/8 细分**，而非任务假设的 1/16 细分（3200）。

## 3. 串口日志摘要

```
Step 2: 开始正转一圈，目标步数：3200
[CMD] 目标位置: 3200 步
[DONE] 当前位置: 3200 步      ← 实际机械转过 2 圈（用户观察）
```

## 4. 最终参数确认

| 参数 | 值 | 说明 |
|---|---|---|
| `SORTER_STEPS_PER_REV` | **1600** | 实测标定，A4988 1/8 细分 |
| 分选位置数 | 6 | 360° 均分 |
| 每位置步数 | 1600 / 6 ≈ 266.67 步 | 整数除法 ±1 步 |
