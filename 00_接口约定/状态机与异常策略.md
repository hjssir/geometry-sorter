## 1 目标状态机（阶段 1 完成后）

```
上电 → BOOT（等 K230 最多 10 s）
        ↓ 超时/失败
     PROBE（发 image，收到任意合法帧 = 在线）→ ERROR
        ↓ 在线
       RUN（每 500 ms 发 image；收 NONE=漏检计数，收 id=识别到）
        ↓
     DETECTED → SORT → RELEASE → DELAY → RESET → RUN
                    ↓ 超时看门狗        ↓
                 ERROR ←──────────────┘
任意状态 ──`e`/物理急停──→ ESTOP ──`r`──→ BOOT
ERROR   ──`r`──────────→ BOOT
```

| 状态 | 进入动作 | 退出条件 | 必须打的日志 |
|---|---|---|---|
| BOOT | 停三级带？否——保持带停，电机使能 | 10 s 或收到 PROBE 应答 | `BOOT` |
| PROBE | 发一次 `image` | 收到任意合法帧（含 `NONE`）→ RUN；10 s 无任何字节 → ERROR | `PROBE online/offline` |
| RUN | 发 `image`，启动三级带 | 收到 id → DETECTED；收到 NONE → 计数；超时 → 计数 | `TX image`、`RX ...` |
| DETECTED | 停三级带，解析 id → 颜色/形状，随机选位 | 立即 | `检测到目标: 标签=37 置信度=87%` |
| SORT | `sorter.moveTo(pos)` | 到位 或 超时 → ERROR | `分选电机 -> 位置 n` |
| RELEASE | `gate.moveTo(711)` | 到位 或 超时 → ERROR | `开合电机 打开` |
| DELAY | 计时 | ≥1000 ms | — |
| RESET | 关开合 + 分选回零 | 两轴到位 | `开合关闭 + 分选复位` |
| ERROR | 停三级带、电机保持使能、**不再发 image** | `r` | `OFFLINE` / `SORT_TIMEOUT` / `PROBE_FAIL` |
| ESTOP | 停三级带、记录、拒绝一切运动指令 | `r`（建议同时要求物理复位） | `ESTOP` |

## 2 异常策略（A4 的落地规则）

| 情形 | 判据 | 动作 | 日志/埋点 |
|---|---|---|---|
| 收到 `NONE` | `finishFrame()` 返回 **0** | `retry++`，**不停带**；`retry ≥ 5` → 记 `MISS`、`retry=0`、放行 | `RETRY n/5`、`MISS`、diag `DG_MISS` |
| 500 ms 内无任何字节 | 超时 | `retry++`；不停带 | `TIMEOUT n` |
| 连续 10 次超时 | ≈5 s（10 × 500 ms） | → `ERROR`，停带、电机保持使能 | `OFFLINE`、diag `DG_OFFLINE` |
| SORT / RELEASE 卡住 | 新增 **`SORT_TIMEOUT_MS`** 看门狗 | → `ERROR` | `SORT_TIMEOUT` |
| 急停 | 串口 `e`（真实模式也读）或物理按钮 | → `ESTOP`，停带 | `ESTOP` |
| 复位 | 串口 `r` | 清 `retry/MISS` 计数、`vlen`、`entered`，回 `BOOT` | `RESET` |

> **关键**：`NONE` 的返回值是 **0**，不是 `-1`。当前 `updateRun()` 只判 `r==1`（`AutoMeasureSort.ino:252`），
> 所以必须显式加 `r==0` 分支，否则 `NONE` 要么被当标签误停带（未加 N1 时），要么被静默吞掉（加了 N1 但不改 `updateRun` 时）。

## 3 当前实现（2026-10-18 核对结果，改动前的基线）

| 项 | 现状 | 证据 |
|---|---|---|
| 状态集合 | `RUN / DETECTED / SORT / RELEASE / DELAY / RESET` 共 6 个 | `AutoMeasureSort.ino:91` |
| 缺的状态 | 无 `BOOT / PROBE / ERROR / ESTOP / SIMULATION` | 同上 |
| 重试计数 | **无**：每 500 ms 无条件重发 | `:257-258` |
| `NONE` / `No objects` | `No objects` 分支 `return 0` 但被 `updateRun` 忽略 → 死代码；`NONE` 会被当正常标签 | `:180、:252` |

| diag 留痕 | 只有正常动作，无一例失败事件；`RESET` 上电恒记 | `diaglog.h:52-62,166-169` |

## 5 合法迁移表（给 `d` dump / 日志时间线分析用）

允许的迁移（出现表外迁移 = 第一个异常点）：

```
BOOT→PROBE  PROBE→RUN  PROBE→ERROR
RUN→DETECTED  RUN→ERROR
DETECTED→SORT  SORT→RELEASE  SORT→ERROR
RELEASE→DELAY  DELAY→RESET  RESET→RUN
*→ESTOP  ESTOP→BOOT  ERROR→BOOT
```

分析 dump 时按此表逐条对照；`ERROR→RUN`、`ESTOP→RUN` 都是非法跳转，必须先回 BOOT。

## 6 阶段 1 实现清单（1-2 ~ 1-5 + 附加项）

| # | 改动 | 通过判据 | 陷阱 |
|---|---|---|---|
| N1 | `finishFrame()` 加 `NONE` 特判（4 行） | 串口助手发 `NONE\n` → 无 `DETECTED`、不停带 | 必须在 1-4 之前；见《接口约定单》N1 |
| 1-2 | 加 `BOOT→PROBE→RUN` | 模拟模式打印 `BOOT→PROBE→RUN`；注入"K230 无响应"→ `ERROR` | PROBE 依赖 `NONE`（N2），否则真机必失败 |
| 1-3 | 加 `ERROR / ESTOP` | 模拟 `e` → `ESTOP`、三级带全 false；`r` 能回 `BOOT` | 复位漏清计数器/`vlen` → 状态卡住 |
| 1-4 | 加 `RETRY_MAX=5` / `OFFLINE_MAX=10` | 连发 5 次 `NONE` → `MISS` 且流程继续；完全无响应 ≈5 s → `ERROR` | `r==0` 必须显式处理；计数要逐次打日志 |
| 1-5 | 加 `SIMULATION_MODE` 开关 | 不接硬件跑完整 5 循环，假 `id=37`，不驱动 IO | 全局搜 `digitalWrite` / `sorter.*` / `gate.*` 防漏 |
| 附加 A | `SORT_TIMEOUT_MS` 看门狗 | 手动堵转 → 超时进 `ERROR` 并打日志 | 与 1-3 一起做，复用 ERROR 动作 |
| 附加 B | 无效帧日志 | 半帧/乱码/超长 → `LOG_WARN("无效帧")` + 计数 | 现在是静默截断（`:199`） |
| 附加 C | diaglog 扩容 | 加 `MISS/TIMEOUT/OFFLINE` 事件；K230 id 扩 **16 位**；解除"5 循环停写" | 改函数签名 → 必须在阶段 2 埋点前完成，否则返工 |

## 7 移植整合版 ERROR/ESTOP 前的 6 条反面清单（照抄会踩坑）

| # | 整合版现状 | 后果 | 做法 |
|---|---|---|---|
| 1 | ERROR 里只 `conveyorStopAll`，**不停电机、无出口**（`GS:286-300`） | 一进 ERROR 只能断电 | 改为停带 + 电机保持使能 + `r` 可复位 |
| 2 | 串口命令只在 `SIMULATION_MODE` 下读（`GS:423`） | 真实模式无法急停/复位 | 命令通道独立于模拟开关 |
