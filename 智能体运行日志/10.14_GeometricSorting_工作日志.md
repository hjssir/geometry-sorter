## 二、对照表解析结果（`reference\对照表.xls`）

`.xls` 为 WPS 生成的 BIFF8 格式，通过解析 OLE2 + SST 记录得到，共 45 个文本单元格，**无任何数字单元格**：

- 表头：`颜色`
- **颜色 13 种**（第 0 行，B1..N1）：红、橙、黄、绿、青、蓝、紫、黑、白、灰、棕、卡其色、粉色
- **形状 31 种**（第 0 列，A2..A32）：半圆、方管、胶囊体、六棱台、六棱柱、镂空正方体、平行六面体、球体、三角筒、三棱台、三棱柱、三棱锥、双锥体、1/4圆、四棱台、四棱锥、椭圆、五角管、五棱台、五棱柱、五棱锥、斜三棱柱、圆环、圆台、圆筒、圆柱体、圆锥体、长方体、正八面体、正方体、斜圆柱体

**关键结论**：对照表只给了「颜色 × 形状」的名称表，**没有给每个物体分配数字编号**。数字编号来自 K230 视觉模型的类别标签表（当前参考目录里视觉脚本为空骨架，未含标签表）。因此「数字 ID → 物体名称」的一一对应暂无法从现有资料补全，已在代码中留 TODO。

## 四、关键设计决策

1. **串口分配**（Mega2560）：
   - Serial（USB，115200）＝调试日志 + 模拟命令
   - Serial1（18/19，9600）＝淘晶驰 TJC 串口屏
   - Serial2（16/17，115200）＝K230 视觉
2. **引脚映射**：
   - 分选电机 STEP=10 / DIR=26；开合电机 STEP=11 / DIR=28；使能 EN=24（低有效，共用）
   - 直流传送带 out1=A1 / out2=A2 / out3=A3
   - 传感器 **44/45**（参考 sketch_oct10a；旧框架为 33/35，已在 config.h 注释说明，待用户二选一确认）
3. **步进电机逻辑**：完全沿用旧程序（AccelStepper 接口类型 1、非阻塞 moveTo+run、6 位置分选、开/关两位置开合），**不重设计算法、不调速度/加速度**，只把旧「类」改写成「全局变量+函数」的简单形式。
4. **主流程**：IDLE → FEED → DETECT → STOP_POS → VISION → DECIDE → SORT → RELEASE → DELAY → RESET → IDLE，另含 ERROR/ESTOP。
5. **视觉解析**：兼容「`标签 置信度`」「`名称,编号`」「单 token」三种格式，非阻塞逐字节累积；"No objects" 靠前缀提前判定。
6. **标签→盒位**：同一标签复用盒位、新标签占空盒、6 盒满→第 7 类（可配停机/放行）。

# 追加：映射表内存优化 + 编译验证（2026-10-14）

## 一、内存优化措施（数学公式法）

对照表为「13 颜色 × 31 形状 = 403 项（编号 0..402）」。**没有**硬编码 403 项结构体数组，
而是用数学公式法：

- `config.h` 只存两个小表：`COLORS[13]` + `SHAPES[31]`（共 44 个字符串指针）。
- 查询公式（`vision.cpp` 的 `getObjectInfo(id, color, shape)`）：
  - `颜色 = COLORS[id % 13]`（`id % COLOR_COUNT`）
  - `形状 = SHAPES[id / 13]`（`id / COLOR_COUNT`）
  - 边界检查：`id < 0 || id >= 403` → 返回 `"UNKNOWN"`，避免数组越界崩溃。

## 二、减少的 SRAM 占用估算

- 若硬编码 `ObjectInfo OBJECT_MAP[403]`（每项约 8 字节指针），约占用 **3.2 KB SRAM**。
- 公式法只存 44 个字符串指针（约 **88 字节**），字符串字面量放 Flash（不占 SRAM）。
- 估算节省 SRAM ≈ **3.1 KB**，对只有 8 KB SRAM 的 Mega2560 意义重大。

## 三、串口屏数字映射

`hmi.cpp` 新增 `hmiShowObject(int objectId)`：把数字 ID 换算成「颜色编号(1..13) + 形状编号(1..31)」
发给串口屏，由屏本地映射成文字/图片。**不直接发中文**，避免串口屏乱码。
（注：示例「红=1，正方体=31」中，正方体实际是 31 项形状的第 30 个，编号应为 30；
斜圆柱体才是 31。实际编号需与屏 HMI 工程核对。）

用 AVR-GCC 7.3.0（Arduino AVR core 1.8.8 + AccelStepper 库）对 Mega2560 完整编译 + 链接：

```
text    data    bss     dec     hex    filename
12952   2628    835     16415   401f   (GeometricSorting)
```

- **无编译错误、无告警**。
- **SRAM 占用 = data + bss = 2628 + 835 = 3463 字节**，占 Mega2560 8 KB 的约 42%，**无内存告警**（剩余约 4.7 KB）。
- Flash 占用 12952 字节（约 5%），充裕。
