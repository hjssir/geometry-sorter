## 3. 关键决策（均依据用户确认，未自行推断）

1. 分选电机 = 步进电机 X（引脚 26/10），6 位置 360° 均分；开合电机 = 步进电机 Y（引脚 28/11），开 80° / 关 0°。
2. 步进统一 A4988，`AccelStepper` 接口类型 1（STEP/DIR），使能 24 低有效且 X/Y 共用。
3. 开合电机参数采用 `StepperAngleTest.ino` **实际代码值** STEPS_PER_REV=3500、80°（**不用注释里的 6400 冲突值**）。
4. 分选电机每圈步数 `StepperMotorTest.ino` 未提供 → 标 TODO（占位 200 步/圈）。
5. 直流传送带 out1/2/3 = A1/A2/A3，单数字 IO，仅上电/断电、单向、无反馈、无 PWM（`setSpeed` 降级为 on/off 并告警）。
6. PZ-D41：NPN 输出，行程开关 X=33、行程开关 Y=35，INPUT_PULLUP，LOW=检测到，软件消抖 200ms。
7. 输送逻辑：三级同时启动；X 触发只停 1 号、Y 触发只停 2 号、视觉开始时停 3 号；复位后三级同时重启。
8. 串口日志波特率 115200。
9. `SIMULATION_MODE=1`（模拟模式）：传感器事件由串口命令注入，电机/传送带只打印动作。

## 4. 状态机设计

`IDLE → FEED → DETECT → STOP_POS → VISION → DECIDE → SORT → RELEASE → DELAY → RESET → IDLE`，另含 `ERROR / ESTOP`。
- 非阻塞实现：步进电机用 `moveTo + run()`，`isBusy()` 判到位。
- 状态机不直接操作引脚，一律经 HAL；视觉/串口屏仅经 `vision_stub_getResult()` / `hmi_stub_show()`。
