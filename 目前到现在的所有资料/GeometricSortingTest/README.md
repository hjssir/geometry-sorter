# GeometricSortingTest —— 几何体分选测试程序（方案 B）

上电自跑、无需电脑、无需传感器。验证「送料 → K230 识别停带 → HMI 显示 → 随机分选 → 循环」完整流程。

## 一、流程图（一个周期）

\`\`\`
上电 ──等10s──▶ 探测K230 ──无响应──▶ HALT(停机)
                  │在线
                  ▼
            启动三级传送带(FEED)
                  │
                  ▼
        循环发 "image" 轮询 K230(VISION)
              │                    │
         收到有效标签           "No objects"/超时
              │                    └──▶ 继续送带、重发 image
              ▼
        停三级传送带 + HMI 显示(DISPLAY)
              ▼
        分选电机→随机位置(0..5)(SORT)
              ▼
        开合电机打开放料(RELEASE)
              ▼
        落料停留 1s(DELAY)
              ▼
        开合关闭 + 分选复位 + 重启传送带(RESET)
              │
              └────────▶ 回到 VISION 循环
\`\`\`

## 二、接线（与主工程 config.h 一致）

| 设备 | 引脚 | 说明 |
|---|---|---|
| 1/2/3 号传送带 | A1 / A2 / A3 | 直流，HIGH=启动 |
| 分选电机 PUL/DIR | 10 / 26 | 闭环步进，脉冲控制 |
| 开合电机 PUL/DIR | 11 / 28 | 闭环步进，脉冲控制 |
| 电机使能 ENA | 24 | 低有效，两轴共用 |
| K230 → Mega | Serial2 RX=16 / TX=17 | 115200 |
| 串口屏 ← Mega | Serial1 TX=18 / RX=19 | 9600 |

## 三、关键参数（均已上机确认，无需再改）

- 电机：16 细分 = **3200 脉冲/圈**（分选 6 位置、开合 80° ≈ 711 脉冲）。
- K230 协议：发 `image` 触发；回 `<标签> <置信度>` 或 `No objects were identified.`。
- HMI：TJC 指令 + `0xFF 0xFF 0xFF` 结束符；控件 `t1`=颜色编号、`t2`=形状编号（与 ji.HMI 一致）。
- 无传感器、无急停、无限循环。

## 四、依赖与烧录

1. Arduino IDE 安装 **AccelStepper** 库。
2. 选择 `Arduino Mega or Mega 2560` + 对应 COM，上传 `GeometricSortingTest.ino`。
3. 上电自跑：D13 无指示（本程序不用 LED），观察 **USB 串口监视器(115200)** 日志即可。

> 提示：想先不接硬件跑逻辑，把 `SIMULATION_MODE` 改 1（视觉返回假结果 id=0，电机/传送带/HMI 不真发）。

## 六、待办 / 注意事项

- **K230 标签表**：若 K230 回传的是名称（如 `红球体`）而非数字编号，程序只记录日志、不映射颜色/形状编号（见 DISPLAY 分支）。数字编号方式下 HMI 才能显示 t1/t2。具体取决于 K230 的 `deploy_config.json` 的 `categories`。
- 分选 6 位置存在 3200/6 非整数带来的 ±1 脉冲舍入，不影响测试。
- HALT（K230 未接入）后需复位板子重试。

## 七、离线诊断日志（diaglog.h）

设备不接串口运行时，把关键事件持久化写入 Mega2560 内置 EEPROM（4KB），事后接串口回读。

### 记录内容
`BOOT`（上电次数+电压）、`STATE`（状态迁移）、`CONV`（传送带启停）、`SORTER`（分选位置/步数）、`GATE`（开合开/关/步数）、`K230`（识别结果/置信度）、`VCC`（电源电压）、`CYCLE`（循环边界）、`RESET`（异常复位+复位前状态）。

### 记录策略
- 记录 **5 个分选循环**后自动停止（`DIAG_MAX_CYCLES` 可改），上电次数始终递增。
- 每次电机动作前采样一次 VCC，用于诊断电源压降。
- 上电时若上次运行未到循环边界（非 CYCLE 收尾），自动记一条 `RESET`。

### 回读 / 清空（事后接电脑，串口 115200）
- 发送 `d` → dump 打印全部日志；发送 `c` → 清空日志。

日志示例：
```
[INFO] 0ms    BOOT #1  VCC=4980mV
[INFO] 10000ms STATE 0 -> 1          (BOOT→PROBE)
[INFO] 10000ms CONV L1/L2/L3 启动
[INFO] 10500ms K230 有效 id=37 conf=95%
[INFO] 10500ms SORTER 位置3 目标1600步
[INFO] 10500ms VCC 4920mV
[INFO] 10500ms GATE 开 目标711步
[INFO] 11000ms CYCLE #1
```
