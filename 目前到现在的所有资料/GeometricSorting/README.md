# GeometricSorting 整合版 —— 使用说明

> 本目录是「Arduino 主控 + 串口屏 + 视觉识别」三模块整合后的工程，
> 结构简单、注释详细、参数集中在 `config.h`，便于后续调试。
>
> 旧版框架仍保留在 `硬件部分/Arduino控制程序/GeometricSorting_control/`，未被删除。

---

## 1. 文件结构

```
GeometricSorting/
├── GeometricSorting.ino   主程序（setup/loop + 状态机 + 标签→盒位映射）

├── vision.h / vision.cpp  K230 视觉串口解析 + 对照表查询
├── hmi.h / hmi.cpp        淘晶驰 TJC 串口屏通信
├── logger.h               串口日志
└── README.md              本说明
```

## 3. 串口分配与协议

| 串口 | 波特率 | 用途 |
|---|---|---|
| Serial（USB） | 115200 | 调试日志 + 模拟命令输入 |
| Serial1（18/19） | 9600 | 淘晶驰 TJC 串口屏 |
| Serial2（16/17） | 115200 | K230 视觉模块 |

### 3.1 Arduino ↔ K230（Serial2）

| 方向 | 内容 | 说明 |
|---|---|---|
| Arduino → K230 | `image` | 触发一次拍照识别 |
| K230 → Arduino | `<标签> <置信度>\n` | 例 `37 0.95` |
| K230 → Arduino | `<名称>,<编号>\n` | 例 `红球体,3`（两种格式都兼容） |
| K230 → Arduino | `No objects were identified.` | 未识别（可能无换行，靠前缀判定） |
| K230 → Arduino | （无回复） | 置信度 ≤ 0.6，由超时处理 |

### 3.2 Arduino → 串口屏（Serial1，TJC 指令）

指令格式：`<控件>.<属性>="值"` + 结束符 `0xFF 0xFF 0xFF`

| 功能 | 指令示例 | 对应函数 |
|---|---|---|
| 显示文本 | `t0.txt="识别中"` | `hmiShowText` |
| 显示识别物体（颜色编号+形状编号） | `t1.val=1`、`t2.val=30` | `hmiShowObject` |
| 显示图片 | `p0.pic=3` | `hmiShowPicture` |
| 数据列表插入 | `data0.insert("1^红球体^3")` | `hmiRecordItem` |

> 控件名 `t0`/`t1`/`t2`/`p0..p5`/`data0` 在 `config.h` 中配置，需按实际 HMI 工程填写。
> 串口屏**不直接收中文**，改收「颜色编号(1..13) + 形状编号(1..31)」，由屏本地映射成文字/图片。

## 4. 对照表说明（数学公式法）

对照表来自 `reference/对照表.xls`，共 **13 种颜色 × 31 种形状 = 403 项**（编号 0..402）：

- **颜色 13 种**：红、橙、黄、绿、青、蓝、紫、黑、白、灰、棕、卡其色、粉色
- **形状 31 种**：半圆、方管、胶囊体、六棱台、六棱柱、镂空正方体、平行六面体、
  球体、三角筒、三棱台、三棱柱、三棱锥、双锥体、1/4圆、四棱台、四棱锥、椭圆、
  五角管、五棱台、五棱柱、五棱锥、斜三棱柱、圆环、圆台、圆筒、圆柱体、圆锥体、
  长方体、正八面体、正方体、斜圆柱体

**不硬编码 403 项大数组**，改用数学公式法（存 `COLORS[13]` + `SHAPES[31]` 两个小表）：

```
数字 ID = 形状序号 × 13 + 颜色序号
颜色 = COLORS[id % 13]   形状 = SHAPES[id / 13]
```

- 查表函数：`getObjectInfo(id, color, shape)`（`vision.cpp`），越界返回 `"UNKNOWN"`。
- 例：`id=0` → 红 + 半圆；`id=12` → 粉色 + 半圆；`id=402` → 粉色 + 斜圆柱体。

> 内存收益：403 项结构体数组约需 2.4KB SRAM，公式法只存 44 个字符串指针（约 88 字节），
> 彻底避免 Mega2560（仅 8KB SRAM）被映射表耗尽。

## 5. 主流程

```
IDLE → FEED(三级全启动) → DETECT(传感器逐级停带) → STOP_POS(停3号,视觉开始)
  → VISION(收K230结果) → DECIDE(查表/分盒) → SORT(分选电机到位)
  → RELEASE(开合电机打开) → DELAY(落料停留) → RESET(复位+三级重启) → IDLE
  另含 ERROR / ESTOP。
```

标签 → 盒位规则：同一标签永远分同一盒；新标签占空盒；6 盒全满 → 第 7 类（停机或放行）。

## 6. 调试方法

### 6.1 模拟模式（不接硬件）

1. `config.h` 里 `SIMULATION_MODE = 1`。
2. 编译上传，串口监视器 115200，行结束符选「换行」。
3. 输入命令（见下）跑通全流程。

| 命令 | 作用 |
|---|---|
| `start` | 启动输送（IDLE→FEED） |
| `x` / `1` | 注入传感器1 触发 |
| `y` / `2` | 注入传感器2 触发 |
| `vision 37` | 设置视觉假标签 |
| `map` | 打印标签→盒位映射 |
| `clear` | 清空映射表 |
| `estop` / `stop` | 急停 |
| `reset` | 从 ESTOP/ERROR 恢复 |
| `status` | 打印当前状态 |
| `help` | 帮助 |

### 6.2 真实硬件

1. `SIMULATION_MODE = 0`。
2. 上电后先等 K230 启动（约 10 秒）。
3. 观察串口日志核对每步动作。

## 7. 待调试 / 待确认项

| 项 | 位置 | 说明 |
|---|---|---|
| 分选电机每圈步数 | `config.h` `SORTER_STEPS_PER_REV` | 旧电机 1600（1/8 细分），**新电机需重新标定** |
| 开合电机每圈步数 | `config.h` `GATE_STEPS_PER_REV` | 旧值 3500（非标准细分），**新电机需标定** |
| 传感器输出极性 | `conveyor.cpp` `readRaw()` | 默认 NPN（LOW=检测），红外传感器需核对 |
| 串口屏控件名 | `config.h` `HMI_*` | `t0`/`t1`/`t2`/`p0`/`data0` 按实际 HMI 工程填写 |
| 数字→物体编号 | `hmi.cpp` `hmiShowObject()` | 颜色编号 1..13、形状编号 1..31，需与屏 HMI 工程的编号一致 |
| 落料停留时间 | `config.h` `RELEASE_DELAY_MS` | 按实际落料时间标定 |
| 视觉超时 | `config.h` `VISION_TIMEOUT_MS` | 按 K230 实测识别耗时调整 |
